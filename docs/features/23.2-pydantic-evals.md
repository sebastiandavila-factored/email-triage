# Eval harness on `pydantic-evals`

> Phase 2 of [exec-plan 23 — Observability + Evals SOTA](../exec-plans/23-observability-evals-sota.md).

## What it does

Re-implements the eval runner on the **`pydantic-evals`** framework
(`Dataset`/`Case`/`Evaluator`/`evaluate`) while keeping every existing metric, the
custom console report, the Logfire `eval.run` span, and DB persistence. This buys us the
framework's tracing, standard report table, and — for free in later phases —
multi-run/`repeat` (Phase 4) and the online-eval capability (Phase 6).

## How it works

```
load_cases(jsonl) → list[EvalCase]
        │
build_dataset(cases, evaluators) → Dataset[TriageRequest, TriageResponse, CaseMeta]
        │                                   (expected category lives in metadata)
dataset.evaluate(task=llm.triage, max_concurrency=5)   ← framework runs + traces
        │
report.cases → results_from_report() → list[EvalResult]   ← adapter
        │
compute_report(results)  (metrics.py UNCHANGED)  → accuracy / macro-F1 / ECE / reliability
        │
print_report(...)        (custom console report, kept)
report.print(...)        (framework's standard table, added)
```

- **Inputs** are `TriageRequest`; the **task** is `await llm.triage(req) -> TriageResponse`.
- **Ground-truth category** is carried in `Case.metadata` (`CaseMeta`), not
  `expected_output` — the latter is typed as the task output (`TriageResponse`).
- **Evaluators** (`evals/evaluators.py`):
  - `CategoryCorrect` → bool assertion (predicted == metadata category).
  - `JudgeQuality` → reuses the existing `JudgeAgent`; numeric scores become report
    *scores*, `language_match` becomes a report *assertion*. The judge is held in a
    module slot (`set_judge`) so no agent/secret is serialized into the evaluator spec.
- **Adapter** `results_from_report()` rebuilds the old `EvalResult` list from
  `report.cases` (output, metadata, and judge scores via `judge_score_from_case`), so
  `metrics.py` is reused **unchanged**.
- **Errored cases:** the framework drops a case from `report.cases` when its task
  raises. The adapter re-adds those (by id difference) with `error` set, so they are
  counted/warned but excluded from metrics — matching the previous behavior.
- **`max_concurrency=5`** replaces the old `asyncio.Semaphore(5)`.
- **Logfire:** the framework emits an experiment span tree + per-case spans (nested
  under our `eval.run` span). The old manual `eval.case` loop is removed (redundant);
  the `eval.run` summary span with `eval.accuracy`/`eval.macro_f1`/`eval.ece` is kept as
  the queryable regression anchor.

## Files involved

| File | Role |
|---|---|
| `evals/dataset_loader.py` | `load_cases()`, `build_dataset()`, typed `TriageDataset`. |
| `evals/evaluators.py` | `CategoryCorrect`, `JudgeQuality`, `set_judge`, `judge_score_from_case`. |
| `evals/run_evals.py` | `run()` rewired to `dataset.evaluate`; `results_from_report()` adapter; both reports. |
| `evals/judge.py` | `JudgeAgent.evaluate(subject, body, draft_reply)` (decoupled from `EvalCase`). |
| `evals/schemas.py` | `CaseMeta` TypedDict. |
| `evals/metrics.py` | **unchanged** — fed by the adapter. |
| `tests/test_evals.py` | unit/integration tests (mock task + stub judge, no Groq). |

## Design decisions

| Decision | Discarded alternative | Reason |
|---|---|---|
| Ground truth in `metadata` | in `expected_output` | `expected_output` is typed as the task output `TriageResponse`. |
| Judge in a module slot via `set_judge` | judge as an evaluator dataclass field | avoids serializing a `JudgeAgent`/API key into the evaluator spec. |
| Reuse `metrics.py` via an adapter | reimplement metrics as evaluators | macro-F1/ECE/reliability are dataset-level, not per-case; keeps numbers identical. |
| Keep custom report **and** `report.print()` | only one | custom has ECE + reliability + misclassified; framework has per-case/assertion drill-down. |
| `max_concurrency=5` | manual semaphore | framework-native; one less moving part. |
| Drop manual `eval.case` spans | keep both | framework already emits per-case spans nested under `eval.run`. |

## Gotchas / Edge cases

- A failed task case **disappears** from `report.cases`; the adapter recovers it via the
  id set difference and marks it errored.
- `evaluate_sync` owns its event loop — call it from **sync** test functions.
- `JudgeQuality` no-ops when no judge is installed (`--no-judge`).
