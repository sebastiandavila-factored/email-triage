# Testing: Online evals on live /triage

> Phase 6 of [exec-plan 23](../exec-plans/23-observability-evals-sota.md).

## Prerequisites

- `.env` with `GROQ_API_KEY` (+ `LOGFIRE_TOKEN` to see eval events).
- To exercise the live path: `ONLINE_EVAL_ENABLED=true` in the env.

## Automated tests

`tests/test_online_evals.py` (no Groq):

| Test | Asserts |
|---|---|
| `test_output_not_empty` | non-empty vs whitespace draft |
| `test_confidence_in_range` | in/out-of-range confidence |
| `test_looks_spanish_heuristic` | Spanish vs English detection |
| `test_language_matches` | match vs mismatch input/reply language |
| `test_build_capability_disabled` | `online_eval_enabled=False` → `None` |
| `test_build_capability_enabled` | enabled → capability built |
| `test_triage_unaffected_with_online_evals` | `/triage` response shape unchanged |

Run: `uv run pytest tests/test_online_evals.py -v`

## Test Cases (manual — real Groq)

### TC-01: disabled by default
**Action**: with `ONLINE_EVAL_ENABLED` unset, start the app and `POST /triage`.
**Expected**: normal response; no `gen_ai.evaluation.result` events.

### TC-02: enabled
**Action**: set `ONLINE_EVAL_ENABLED=true` (optionally `ONLINE_EVAL_SAMPLE_RATE=1.0` to
force sampling), restart, `POST /triage`.
**Expected**: identical response and latency; `gen_ai.evaluation.result` events appear in
Logfire for the sampled runs (output-not-empty, confidence-in-range, language-matches).

### TC-03: no latency regression
**Action**: `make ttft` with online evals on vs off.
**Expected**: no measurable TTFT change (evals dispatch after the run).

## Edge Cases

| Scenario | Expected |
|---|---|
| `online_eval_enabled=False` | `/triage` behaves exactly as before |
| sample_rate 0.05 | ~5% of runs produce eval events |
| evaluator raises internally | handled by the capability; never affects the response |

## Log verification

- Logfire: filter for `gen_ai.evaluation.result` events on the `assistant` agent.

## Troubleshooting

| Symptom | Cause | Solution |
|---|---|---|
| No eval events | disabled, or sample_rate too low | set `ONLINE_EVAL_ENABLED=true`, raise sample_rate |
| Latency rose | misconfiguration | confirm evals dispatch async; lower `max_concurrency`/`sample_rate` |
| Language flag noise | heuristic limits | expected on short/code-mixed text; it never blocks |
