> Phase 7 of [exec-plan 23](../exec-plans/23-observability-evals-sota.md).

## Prerequisites

- None for automated tests. `GROQ_API_KEY` only for live smoke.

## Automated tests

`tests/test_evals.py` (no Groq):

| Test | Asserts |
|---|---|
| `test_suite_sizes` | regression=25, capability=20, all=45 |
| `test_regression_suite_is_category_balanced` | regression 5 per category |
| `test_capability_suite_is_category_balanced` | capability 4 per category |
| `test_every_case_has_valid_source` | every case `source ∈ {real, synthetic}` |
| `test_loader_rejects_case_missing_source` | missing `source` → `ValidationError` |

Run: `uv run pytest tests/test_evals.py -k "suite or source or balanced" -v`

## Test Cases (manual — real Groq)

### TC-01: source line in report
**Action**: `uv run python -m evals.run_evals --suite capability --no-judge --filter difficulty=medium`
**Expected**: report shows `Source  real 0 · synthetic N`.

### TC-02: filter by source
**Action**: `uv run python -m evals.run_evals --suite all --no-judge --filter source=synthetic`
**Expected**: runs all 45 cases (all synthetic today).

### TC-03: balance holds on a full run
**Action**: `make eval-capability`
**Expected**: 20 cases, 4 per category in the per-category table.

## Edge Cases

| Scenario | Expected |
|---|---|
| dataset row without `source` | rejected at load (`ValidationError`) |
| `--filter source=real` today | "No cases matched", exit 1 (no real cases yet) |

## Troubleshooting

| Symptom | Cause | Solution |
|---|---|---|
| `ValidationError` loading a suite | a row is missing `source` | add `"source":"synthetic"` (or `"real"`) to the row |
| Imbalanced per-category table | a suite drifted | re-check counts; capability must be 4×5, regression 5×5 |
