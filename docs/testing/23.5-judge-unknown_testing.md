# Testing: Judge with "Unknown" verdict + calibration seam

> Phase 5 of [exec-plan 23](../exec-plans/23-observability-evals-sota.md).

## Prerequisites

- `.env` with `GROQ_API_KEY` for live runs.

## Automated tests

`tests/test_evals.py` (no Groq):

| Test | Asserts |
|---|---|
| `test_judge_score_assessable_requires_all_scores` | validator rejects assessable without all 5 scores |
| `test_judge_score_unknown_allows_empty` | unknown verdict → None fields allowed |
| `test_unknown_excluded_from_means_but_counted` | means over assessable; `judge_unknown_rate=0.5` |
| `test_all_unknown_yields_no_means` | all unknown → no means, rate=1.0 |
| `test_no_judge_unknown_rate_is_none` | no judge → rate None |
| `test_export_calibration_sample` | writes parseable JSONL, judged-only, `human_verdict` null |

Run: `uv run pytest tests/test_evals.py -k "judge or unknown or calibration" -v`

## Test Cases (manual — real Groq)

### TC-01: judge runs, no abstention
**Action**: `uv run python -m evals.run_evals --suite capability --filter difficulty=medium`
**Expected**: LLM JUDGE section with means + `Unknown rate 0.0 %`.

### TC-02: calibration export
**Action**: add `--judge-sample 5` to TC-01.
**Expected**: a `Calibration sample → evals/calibration/<ts>.jsonl` line; the file has one
row per judged case with `judge_verdict`, scores, `judge_reason`, `human_verdict: null`.

### TC-03: abstention path
**Action**: hard to force deterministically; review whether any real case yields
`verdict=unknown` over a full `make eval`. If the rate is high, tighten the rubric.

## Edge Cases

| Scenario | Expected |
|---|---|
| all cases assessable | `Unknown rate 0.0 %`, means present |
| all cases unknown | no means printed, `Unknown rate 100.0 %` (red) |
| `--no-judge` | no LLM JUDGE section; `--judge-sample` ignored |

## Log verification

- DB persistence stores `judge_overall`/`judge_language_match` as null for unknown cases.

## Troubleshooting

| Symptom | Cause | Solution |
|---|---|---|
| `ValidationError` from the judge | model returned assessable with missing scores | pydantic-ai retries; if persistent, tune the prompt |
| high Unknown rate | judge over-abstaining | tighten "do NOT abstain just because…" in the rubric |
| empty `judge_reason` | weak model ignored the instruction | acceptable; reason is best-effort |
