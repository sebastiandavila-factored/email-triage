# Testing: Eval harness on `pydantic-evals`

> Phase 2 of [exec-plan 23](../exec-plans/23-observability-evals-sota.md).

## Prerequisites

- `.env` with `GROQ_API_KEY` (for the live `make eval*` smoke). `DATABASE_URL` optional
  (persistence is a no-op without it). `LOGFIRE_TOKEN` optional (traces).
- `uv sync` (pulls `pydantic-evals`).

## Automated tests

`tests/test_evals.py` — no Groq, no network (mock task + `StubJudge`):

| Test | Asserts |
|---|---|
| `test_load_cases_parses_full_dataset` | 40 cases, all 5 categories present |
| `test_load_cases_applies_filters` | `difficulty=hard` filter works |
| `test_build_dataset_carries_inputs_and_metadata` | `Case.inputs` is `TriageRequest`, metadata has `expected_category` |
| `test_end_to_end_metrics_and_judge_reconstruction` | `evaluate_sync` → adapter → `compute_report`; accuracy 0.5; judge scores rebuilt |
| `test_no_judge_yields_none_scores` | no judge → `judge_score is None` |
| `test_judge_score_from_case_none_without_judge` | reconstruction returns None |
| `test_dropped_case_becomes_error_result` | dropped/errored case re-added with `error` |

Run: `uv run pytest tests/test_evals.py -v`

## Test Cases (manual smoke — uses real Groq)

### TC-01: classification only
**Action**: `uv run python evals/run_evals.py --no-judge --filter difficulty=medium`
**Expected**: custom report (accuracy, macro-F1, calibration, reliability) **and** the
framework's "Evaluation Summary" table; `eval_run.persisted` log if DB configured.

### TC-02: with judge
**Action**: `uv run python evals/run_evals.py --filter difficulty=medium`
**Expected**: an "LLM JUDGE" section with means; the framework table shows
`judge_relevance/tone/correctness/overall` scores and ✔✔ assertions.

### TC-03: full suite
**Action**: `make eval-quick` / `make eval`
**Expected**: 40 cases; accuracy ≥ 85%, ECE < 0.10 (same targets as plan 13).

## Edge Cases

| Scenario | Expected |
|---|---|
| `--filter key=value` with no matches | prints "No cases matched", exits 1 |
| Groq error on a case | case dropped from framework report, re-added as errored, excluded from metrics, warned |
| No `DATABASE_URL` | persistence is a no-op |
| No `LOGFIRE_TOKEN` | runs locally; no traces sent |

## Log verification

- `eval_run.persisted` (structlog) with `run_id`, `n_cases` when DB is configured.
- Logfire: `eval.run` span with `eval.accuracy`/`eval.macro_f1`/`eval.ece`; framework
  per-case spans nested underneath.

## Troubleshooting

| Symptom | Cause | Solution |
|---|---|---|
| `RuntimeError: event loop is running` in a test | calling `evaluate_sync` from an async test | make the test `def`, not `async def` |
| Judge scores all None | `set_judge` not called / `--no-judge` | install the judge before `evaluate` |
| Metrics differ from old harness | adapter mismapping | check `results_from_report` field mapping |
