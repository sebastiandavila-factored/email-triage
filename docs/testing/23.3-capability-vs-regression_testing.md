# Testing: Capability vs regression suites

> Phase 3 of [exec-plan 23](../exec-plans/23-observability-evals-sota.md).

## Prerequisites

- `.env` with `GROQ_API_KEY` for live runs. DB/Logfire optional.

## Automated tests

`tests/test_evals.py` (no Groq):

| Test | Asserts |
|---|---|
| `test_suite_sizes` | regression=25, capability=15, all=40 |
| `test_regression_suite_is_category_balanced` | regression is 5 per category |
| `test_all_suite_covers_every_category` | union covers all 5 categories |
| `test_load_suite_applies_filters` | `difficulty=hard` filter on capability |
| `test_passes_threshold` | gate comparison: `>=` semantics |

Run: `uv run pytest tests/test_evals.py -v`

## Test Cases (manual — real Groq)

### TC-01: capability suite
**Action**: `make eval-capability`
**Expected**: report header `suite:capability`, 15 cases, GATE vs 0.70.

### TC-02: regression gate
**Action**: `make eval-regression`
**Expected**: header `suite:regression`, 25 cases, GATE vs 0.95, PASS (the two ambiguous
status cases were recurated into `capability`; see the feature doc). The GATE line also
shows the error rate and FAILs if `error_rate > 20%` even at high accuracy.

### TC-03: single-file override
**Action**: `uv run python -m evals.run_evals --dataset evals/datasets/capability.jsonl --no-judge`
**Expected**: runs that file with the default 0.85 threshold; no suite name.

## Edge Cases

| Scenario | Expected |
|---|---|
| `--check` and accuracy ≥ threshold | exit 0, GATE PASS |
| `--check` and accuracy < threshold | exit 1, GATE FAIL |
| no `--check` | always exit 0, GATE line still printed |
| `--filter` with no matches | "No cases matched", exit 1 |

## Log verification

- `eval.run` span attributes: `eval.suite`, `eval.threshold`, `eval.passed`,
  plus `eval.accuracy`/`eval.macro_f1`/`eval.ece`.

## Troubleshooting

| Symptom | Cause | Solution |
|---|---|---|
| `eval-regression` exits 1 | known finding (borderline status cases) | recurate `status-003/004` or tune the prompt |
| `KeyError` on suite name | typo in `--suite` | use regression/capability/all |
